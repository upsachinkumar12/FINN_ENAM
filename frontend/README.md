# FINN web app

React + Vite + Tailwind. See the [project README](../README.md) for setup, and [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for how it fits together.

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to http://127.0.0.1:8000
npm run build   # type-check and production build into dist/
```
